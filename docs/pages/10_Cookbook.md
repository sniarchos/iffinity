# {{ page.title }}

The rest of these pages describe what iffinity *is*. This one is about what you *do with it*.

Each recipe starts from a problem an author actually has, shows working code, and says why the code is shaped the way it is. Where a recipe has a runnable counterpart, it links to the [examples]({{ site.baseurl }}/examples/).

The code here is not invented for the page. It comes from real stories built on iffinity, so where a recipe warns you about something, it is because that thing went wrong for somebody first.

## Recipes

- [Porting a story from Twine/Snowman]({{ site.baseurl }}/cookbook/porting-from-twine/): what changes, what breaks quietly, and how to check you moved everything.

More to come. If you have solved something with iffinity that took you a while to work out, that is exactly what belongs here, so [open an issue](https://github.com/sniarchos/iffinity/issues) and I'll be sure to add your recipe in this cookbook!
